Este proyecto implementa un sistema simple de Programación Orientada a Objetos (POO) en Python utilizando herencia, composición, encapsulamiento y métodos de comportamiento.

El sistema contiene 5 clases distribuidas en archivos separados para mantener claridad y organización. incluye: una superclase (Vehiculo), dos clases hijas (Automovil y Motocicleta), una clase de composición (Motor) y un programa principal que demuestra su funcionamiento. 

 Cada clase utiliza encapsulamiento mediante @property y @setter, incluye métodos de comportamiento, y define su propia versión de __str__ () para mostrar información de forma clara.

 Las clases hijas heredan de Vehiculo y, además, integran un objeto Motor usando composición.

 El programa principal crea varios automóviles y motocicletas, asigna un motor a cada uno y ejecuta diferentes métodos para evidenciar herencia.
 
 Finalmente, imprime los objetos para verificar que toda la estructura funciona correctamente.
